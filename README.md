# Lịch âm & Thập trai 2026–2030

Lịch âm Việt Nam (tính theo múi giờ UTC+7) dạng file `.ics` cho iPhone, Mac, Google Calendar, Outlook.

- `am-lich-2026-2030.ics` — ngày âm cho các ngày thường, kèm Rằm, lễ Tết và năm Can Chi vào ngày mùng 1
- `thap-trai-2026-2030.ics` — 10 ngày Thập trai mỗi tháng (🪷): 1, 8, 14, 15, 18, 23, 24 và 28–29–30 (tháng đủ) hoặc 27–28–29 (tháng thiếu)

Hai file bổ sung cho nhau (mỗi ngày chỉ nằm trong một file), nên nhập mỗi file vào một lịch riêng và đặt màu nổi cho lịch Thập trai.

## Cách dùng
1. Tạo 2 lịch mới: "Âm lịch" và "Thập trai".
2. Tải file `.ics` và nhập vào đúng lịch (Mac: Tệp → Nhập…; iPhone: mở file → Thêm tất cả).

Ngày âm được tính theo thuật toán của Hồ Ngọc Đức.
